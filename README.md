
# Student Performance Analysis & Prediction System

A Python and Data Science project to analyze student performance and predict scores based on study-related factors.

## 📌 Project Overview

This project analyzes student-related data to understand the relationship between study habits and academic performance.

The project includes data processing, data analysis, and visualization of factors such as study hours, attendance, and final scores.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Data Analysis
- Data Visualization
- Machine Learning

## 📊 Project Analysis

The project includes visualizations such as:

- Study Hours vs Final Score
- Attendance vs Final Score

These visualizations help identify patterns between students' study habits, attendance, and academic performance.
